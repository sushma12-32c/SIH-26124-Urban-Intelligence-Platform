## How to Create This Slide:

### **Option 1: PowerPoint/Google Slides**
1. Create new slide with "Title Only" layout
2. Add title: "Feasibility & Impact Assessment"
3. Insert text box (left 50%) → paste 5 bullet points
4. Insert image (right 50%) → add relevant photo
5. Adjust font: Title 44pt, Bullets 24pt
6. Colors: Professional (blue/green theme)

### **Option 2: Canva (Free)**
1. Go to canva.com → search "presentation slide"
2. Choose template with left text + right image layout
3. Paste 5 bullet points in left section
4. Upload image to right section
5. Download as PNG/PDF
